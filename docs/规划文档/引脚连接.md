## 接线总览

- **主控分工**：ESP32-CAM 负责视频与网络，STM32F103C8T6 负责舵机、OLED、按键。
- **两板之间**：只走一组 UART：ESP32 GPIO13/14 ↔ STM32 PA10/PA9。
- **两个 SG90 舵机**：信号接 STM32：PA6（PAN）和 PA7（TILT）。
- **OLED**：走 I2C：PB6（SCL）+ PB7（SDA）。
- **按键**：接 PB12 到 GND（内部上拉输入，按下为低电平）。
- **共地**：所有模块必须共地（ESP32、STM32、舵机、OLED、电源 GND 全连一起）。

## 引脚与元件对应

- **ESP32 GPIO13 (UART2 TX)** → **STM32 PA10 (USART1_RX)**（ESP 发给 STM）
- **ESP32 GPIO14 (UART2 RX)** ← **STM32 PA9 (USART1_TX)**（STM 回给 ESP）
- **STM32 PA6 (TIM3_CH1)** → **舵机1 信号线**（PAN 水平）
- **STM32 PA7 (TIM3_CH2)** → **舵机2 信号线**（TILT 垂直）
- **STM32 PB6 (I2C1_SCL)** → **OLED SCL**
- **STM32 PB7 (I2C1_SDA)** → **OLED SDA**
- **STM32 PB12** → **按键一端**，按键另一端 → **GND**
- **（可选电池采样）STM32 PA0 (ADC1_IN0)** ← R1/R2 分压中点（见下方阻容接法）

## 阻容接法（与 KiCad 原理图一致）

> 以下所有阻容器件编号、参数和网络连接均以 `aquasentinel-hardware.kicad_sch` 为准。

### 为什么需要这些阻容

整套电路只有 5V 一路电源，同时给 ESP32-CAM、STM32、两颗舵机和 OLED 供电。舵机启动瞬间电流可达 500mA 以上，ESP32 的 WiFi 射频 bursts 也会在短时间内抽取大电流，这些都可能把 5V 电源拉低到 3V 以下，导致 STM32 或 ESP32 看门狗复位。电池电压 3.0\~4.2V 超出 STM32 ADC 的 0\~3.3V 量程，必须分压后才能安全采样。下面的阻容就是针对这两个问题加的。

### 电容

| 位号 | 参数 | 脚1（+） | 脚2（-） | 作用 |
|------|------|----------|----------|------|
| C1 | 470uF/10V（optional） | VCC_5V | GND | **储能电容**：舵机启动/换向瞬间电流远超平均值（SG90 堵转约 500mA），470uF 电解电容在 5V 电源上充放电，可避免舵机动作时把 5V 拉低导致 ESP32 或 STM32 复位。C1 和 C2 并联在同一 VCC_5V/GND 网络上，面包板阶段摆放位置无实质差异，都接到 5V 主干即可。 |
| C2 | 100uF/10V（optional） | VCC_5V | GND | **去耦电容**：ESP32-CAM 的 WiFi 射频每隔几十 ms 发射约 300mA 峰值电流，100uF 电解电容可平滑这一脉冲，减少电源纹波对 STM32 和 OLED 的干扰。C1 和 C2 并联在同一 VCC_5V/GND 网络上，面包板阶段摆放位置无实质差异。若做 PCB 则应尽量靠近各负载的电源引脚放置。 |

接线示意：
```
5V 主干 ────┬──── C1(+) ──── C1(-) ──── GND     ← 470uF 储能
             └──── C2(+) ──── C2(-) ──── GND     ← 100uF 去耦
（C1、C2 并联在同一网络，面包板阶段位置不限；PCB 阶段宜靠近对应负载引脚）
```

### 电阻

| 位号 | 参数 | 脚1 | 脚2 | 作用 |
|------|------|-----|-----|------|
| R1 | 100k（optional） | BAT_SENSE（分压中点 → STM32 PA0） | BATT_POS（电池正极） | **ADC 分压上臂**：与 R2 串接在电池正极与 GND 之间，将 3.0\~4.2V 的电池电压等比缩小到 1.5\~2.1V，使 STM32 的 0\~3.3V ADC 能安全采样。 |
| R2 | 100k（optional） | GND | BAT_SENSE（分压中点 → STM32 PA0） | **ADC 分压下臂**：与 R1 构成 1:1 分压，分压比 = R2/(R1+R2) = 0.5，所以 ADC 读数 × 2 ≈ 实际电池电压。选 100k 是为了将分压支路静态电流限制在约 42uA（4.2V / 200k），避免持续消耗电池。 |

接线示意：
```
BATT_POS ── R1(100k) ──┬── R2(100k) ── GND
                        │
                   BAT_SENSE（→ STM32 PA0）

换算：battery_mv = adc_raw × 3300 × 2 / 4096
```

### 未画进原理图的建议电容

> 如果实测时 OLED 出现闪烁或花屏，可在 OLED 模块的 VCC 与 GND 之间就近（尽量贴着 OLED 引脚）并联一颗 **100nF 陶瓷电容**，用于滤除 I2C 通信和 OLED 刷新时的电源高频毛刺。

## 电源开关

在升压模块 5V 输出与 VCC_5V 主干之间串联一个电源开关，控制整套电路的通断：

```
电池 3.7V → 升压模块 → [开关] → VCC_5V 主干 → ESP32 / STM32 / 舵机 / C1 / C2
                       ↑                ↑
                    开关前             开关后
                   (BATT_POS)        (VCC_5V)
```

- **开关位置**：串联在升压模块 5V 输出与 VCC_5V 主干之间（仅断正极，GND 始终连通）。
- **开关断开时**：VCC_5V 失电，ESP32、STM32、舵机、OLED 全部断电；升压模块仍接电池，静态耗电约 1\~2mA。
- **开关类型**：推荐拨动开关（如 SS12D00），额定电流 ≥2A（舵机堵转约 1A）。
- **R1/R2 分压不受影响**：分压电阻在电池侧（BAT_POS → BATT_POS），开关断开时仍通路，静态耗电仅约 42uA，可忽略。

## 电源接法（关键）

- **5V 供电路径**：电池 → 升压模块 5V → **开关** → VCC_5V 主干 → 同时供给：ESP32-CAM 5V、STM32 5V、两个舵机红线(VCC)。
- **GND 连通**：升压模块 GND 同时接：ESP32 GND、STM32 GND、两个舵机棕线(GND)、OLED GND。（GND 不经过开关）
- **OLED 电压**：建议从 STM32 3.3V 供电：STM32 3.3V -> OLED VCC。
- **电量指示**：电量指示板独立接电池：B+ 到电池正，B- 到电池负。（不受开关影响，始终可显示电量）

## 注意事项（避坑指南）

- **UART 交叉**：UART 一定是 TX 对 RX 交叉接，别同名直连。
- **GPIO12 避坑**：不要用 ESP32 的 GPIO12 做 UART（启动风险），当前方案改成 GPIO13/14 就是为了解这个问题。
- **舵机电流**：舵机供电走 5V 主干，不要从 STM32/ESP32 的 3.3V 或板上 5V 引脚给舵机取大电流。
- **滤波电容**：C1(470uF) 和 C2(100uF) 并联在 VCC_5V 与 GND 之间，面包板阶段摆放位置无实质差异，都接到 5V 主干即可；OLED 旁的 100nF 见上方阻容接法章节的备注。
