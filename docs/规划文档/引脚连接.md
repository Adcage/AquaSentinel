## 接线总览

- **主控分工**：ESP32-CAM 负责视频与网络，STM32F103C8T6 负责舵机、OLED、按键。
- **两板之间**：只走一组 UART：ESP32 GPIO13/14 ↔ STM32 PA10/PA9。
- **两个 SG90 舵机**：信号接 STM32：PA6（PAN）和 PA7（TILT）。
- **OLED**：走 I2C：PB6（SCL）+ PB7（SDA）。
- **按键**：接 PB12 到 GND（内部上拉输入，按下为低电平）。
- **共地**：所有模块必须共地（ESP32、STM32、舵机、OLED、电源 GND 全连一起）。

## 引脚与元件对应

- **ESP32 GPIO13 (UART2 TX)** → **STM32 PA10 (USART1_RX)**（ESP 发给 STM）
- **ESP32 GPIO14 (UART2 RX)** ← **STM32 PA9 (USART1_TX)**（STM 回给 ESP）
- **STM32 PA6 (TIM3_CH1)** → **舵机1 信号线**（PAN 水平）
- **STM32 PA7 (TIM3_CH2)** → **舵机2 信号线**（TILT 垂直）
- **STM32 PB6 (I2C1_SCL)** → **OLED SCL**
- **STM32 PB7 (I2C1_SDA)** → **OLED SDA**
- **STM32 PB12** → **按键一端**，按键另一端 → **GND**
- **（可选电池采样）STM32 PA0 (ADC1_IN0)** ← 100k/100k 分压中点，中点并 100nF 到 GND

## 电源接法（关键）

- **5V 供电**：升压模块 5V 同时供给：ESP32-CAM 5V、STM32 5V、两个舵机红线(VCC)。
- **GND 连通**：升压模块 GND 同时接：ESP32 GND、STM32 GND、两个舵机棕线(GND)、OLED GND。
- **OLED 电压**：建议从 STM32 3.3V 供电：STM32 3.3V -> OLED VCC。
- **电量指示**：电量指示板独立接电池：B+ 到电池正，B- 到电池负。

## 注意事项（避坑指南）

- **UART 交叉**：UART 一定是 TX 对 RX 交叉接，别同名直连。
- **GPIO12 避坑**：不要用 ESP32 的 GPIO12 做 UART（启动风险），当前方案改成 GPIO13/14 就是为了解这个问题。
- **舵机电流**：舵机供电走 5V 主干，不要从 STM32/ESP32 的 3.3V 或板上 5V 引脚给舵机取大电流。
- **滤波电容**：建议加电容：舵机支路 470uF，ESP32 旁 100uF，OLED 旁 100nF，能明显减少重启/闪屏/断流。
