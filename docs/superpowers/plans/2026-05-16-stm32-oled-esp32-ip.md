# STM32 OLED 显示 ESP32 IP 地址 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 STM32 的 OLED 屏幕上新增"网络"页面，显示 ESP32-CAM 通过 UART 推送的 WiFi IP 地址。

**Architecture:** ESP32 WiFi 连接成功后，通过 UART 发送 `IP:<ip>\n` 给 STM32。STM32 的 `UartHandler` 识别该命令并存储 IP 到全局缓冲区。OLED 新增 `OledPage::Network` 页面，短按 PB12 切到该页时显示 IP 或"未连接"。

**Tech Stack:** PlatformIO、STM32duino (Arduino framework)、C++11、现有 UART 协议、SSD1306 I2C OLED 驱动。

- [ ] **Step 2: 修改 UartHandler.cpp，实现 IP 命令解析**

将构造函数从：

```cpp
UartHandler::UartHandler(PtzServo& servoRef) : servo(servoRef) {}
```

改为：

```cpp
UartHandler::UartHandler(PtzServo& servoRef, char* ipBufferRef) : servo(servoRef), ipBuffer(ipBufferRef) {}
```

在 `handleLine()` 方法中，在 `if (line == ptz_protocol::CMD_HOME)` 之前添加 IP 命令识别：

```cpp
    if (line.startsWith(ptz_protocol::CMD_IP)) {
        String ipStr = line.substring(3);
        ipStr.trim();
        if (ipStr.length() > 0 && ipStr.length() <= 15 && ipBuffer != nullptr) {
            ipStr.toCharArray(ipBuffer, 16);
        }
        return;
    }
```

这段代码放在 `handleLine()` 中 `line.trim()` 和空行检查之后、`CMD_HOME` 判断之前，因为 `IP:` 是单向推送不需要回复，且应优先于 `BAD_CMD` 判定处理。

bool OledDisplay::hasStateChanged(const OledUiState& current, const OledUiState& previous) {
    if (current.page != previous.page ||
        current.showActionMessage != previous.showActionMessage ||
        strcmp(current.actionMessage, previous.actionMessage) != 0) {
        return true;
    }

    return current.pan != previous.pan ||
           current.tilt != previous.tilt ||
           current.calibrationMode != previous.calibrationMode ||
           current.panPulseUs != previous.panPulseUs ||
           current.tiltPulseUs != previous.tiltPulseUs ||

void UartBridge::sendIp(const String& ip) {
    String cmd = bridge_protocol::CMD_IP_PREFIX;
    cmd += ip;
    cmd += "\n";
    serial.print(cmd);
}

注意：`sendIp()` 不使用 `sendCommand()` 等待回复，因为 `IP:` 是单向推送，STM32 不回复。

- [ ] **Step 3: 在 ESP32 main.cpp 中 WiFi 连接成功后推送 IP**

完整的 `connectWiFi()` 改为：

```cpp
void connectWiFi() {
    Serial.println("正在连接WiFi...");
    WiFi.begin(cam_config::WIFI_SSID, cam_config::WIFI_PASSWORD);
    int attempts = 0;
    while (WiFi.status() != WL_CONNECTED && attempts < 20) {
        delay(500);
        Serial.print('.');
        attempts++;
    }
    if (WiFi.status() == WL_CONNECTED) {
        Serial.println("\nWiFi连接成功");
        Serial.print("IP地址: ");
        Serial.println(WiFi.localIP());
        g_uartBridge.sendIp(WiFi.localIP().toString());
    } else {
        Serial.println("\nWiFi连接失败");
    }
}
```
